# neurodesk

Builds the Neurodesktop environment for the Nectar Virtual Desktop Service
(Bumblebee). It is a manual translation of the upstream Neurodesktop
Dockerfile at https://github.com/neurodesk/neurodesktop into an OS image:
upstream bakes Guacamole/VNC into a container, whereas our image is a full
Ubuntu VM with XRDP, and Guacamole is external (Bumblebee). Container-only
parts of the Dockerfile (Guacamole, Tomcat, VNC, healthchecks, the jovyan
home-seeding model) are deliberately not replicated here.

## Relationship to upstream

- `UPSTREAM_REF` pins the upstream commit this role was last synced from.
- `files/upstream/` contains byte-for-byte copies of upstream files, listed
  in `files/upstream/MANIFEST` and regenerated by
  `scripts/neurodesk-vendor-upstream.sh`. Never edit them by hand; the
  directory is excluded from pre-commit formatting hooks.
- `files/config/` contains files that deliberately differ from upstream
  (or have no upstream equivalent), for example:
  - `neurodesktop.sh`: our profile.d entry point (no upstream equivalent)
  - `lxde/lxterminal.conf`, `lxde/panel`, `lxde/background.png`: local
    desktop tweaks
  - `jupyter/*.sh`: locally adapted startup scripts
- `files/cvmfs/`, `files/setup-cvmfs.*`, `files/neurocommand-update.*`:
  our own VM/systemd arrangement of upstream's CVMFS and neurocommand
  setup.

## Syncing with upstream

1. `scripts/neurodesk-upstream-diff.sh -l` shows upstream commits and a
   diffstat since `UPSTREAM_REF` (drop `-l` for the full diff). Target the
   latest upstream GitHub release by default.
2. Translate applicable Dockerfile changes into the role (packages and pip
   lists live in `defaults/main.yml` and `vars/default.yml`; ignore
   container-only changes).
3. Update `UPSTREAM_REF` to the ref you synced to and run
   `scripts/neurodesk-vendor-upstream.sh` to re-vendor `files/upstream/`.
4. Review `git diff`. If a vendored file was deleted upstream, the vendor
   script fails on it: remove it from the MANIFEST and from the task that
   installs it, or move a local copy into `files/config/`.
